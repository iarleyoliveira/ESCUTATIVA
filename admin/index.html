Redação Escutativa

Área da equipe

Crie e edite matérias, envie imagens e atualize os vídeos do projeto no editor de conteúdo.

Entrar no editor

Entre com sua conta autorizada e selecione iarleyoliveira / ESCUTATIVA / main. Todos os integrantes com acesso podem publicar diretamente.

  1. Abra Matérias e crie um novo texto.
  2. Preencha título, resumo, autor, data, capa e conteúdo.
  3. Ative Publicar no site quando estiver pronto e salve.
  4. Aguarde a atualização do GitHub Pages.
Antes do primeiro acesso: o responsável precisa autorizar o aplicativo Pages CMS neste repositório e cadastrar os integrantes.
Rascunhos: ficam fora do site, mas são visíveis nos arquivos públicos do GitHub. Não salve informações confidenciais.
